## Brief Script Overview

Input:

- Hyperstack TZCYX .tif(f) file
- Run Parameters given via cmd parser or as .json config dictionary file

Steps taken:

1. Segmentation at specific channel & time point
    1. Pre-Processing of image using blur & threshold
    2. Marching Cubes surface algorithm to generate "upper"/"lower" surface
    3. Sphere fit to "upper" surface
    4. Cropping of sphere to spherical cap
2. Projection for all channels & time points
    1. Sampling of interpolatd intensities at set distances sampled from the sphere mesh "inwards"
    2. Max/mean of projected sliced
3. Saving of final radial 8-bit hyperstack and spherical coordinate metadata

Output in output folder:

```
img_name/  
├── t-0_c-0/                    # Sub-result for a specific time point and channel
│   ├── data/                   # Raw projection and/or segmentation data
│   └── figures/                # Figures to check projection and/or segmentation
|   ...
├── radial_hyperstack.tiff      # Projected Radial Hyperstack
└── coordinate_metadata.tiff    # Coreesponding spherical coordinate metadata
```  

4. Post-Processing using FIJI plugin at "/nemo/embl_spherical_projection/line_measure.ijm"
    1. Specify path to metadata .fiji file generated by NEMO
    2. Select lines in ROI manager
    3. Conversion is perfomed using simple $ds \approx R \sqrt{\Delta \theta ^2 + \sin^2(\theta) \Delta \phi^2}$
    4. Output saves line measurements in .csv file.

## Execution

- To use it using a custom .json dictionary file containing all parameters, run:

    ```bash
    python .../nemo/batch_analysis/embl_spherical_projection/spherical_projection.py --config ".../nemo/auto_spherical_projection/run_params.json"
    ```  
- or else run it directly using the parsed arguments:
    ```bash
    python .../nemo/batch_analysis/embl_spherical_projection/spherical_projection.py --img_path ".../hyperstack.tif" --result_path ".../result_folder/" --segment --project --savetiff
    ```

## Script Parameters

### Command-Line Arguments

| Argument                   | Type    | Default  | Description                                            |
|----------------------------|---------|----------|--------------------------------------------------------|
| `--config`                 | `str`   | –        | Path to JSON config file (optional, overwrites rest).  |
| `--img_path`               | `str`   | –        | Path to input `.tiff` image.                           |
| `--result_path`            | `str`   | –        | Directory to save results.                             |
| `--segment`                | `bool`  | `False`  | Run segmentation.                                      |
| `--project`                | `bool`  | `False`  | Run projection.                                        |
| `--savetiff`               | `bool`  | `False`  | Save radial hyperstack as `.tiff`.                     |
| `--t_segmentation`         | `int`   | `0`      | Time index for segmentation. (integer !)               |
| `--c_segmentation`         | `int`   | `0`      | Channel index for segmentation. (integer !)            |
| `--min_proj_dist`          | `float` | `5.0`    | Minimum distance for projection.                       |
| `--max_proj_dist`          | `float` | `120.0`  | Maximum distance for projection.                       |
| `--proj_thickness`         | `float` | `20.0`   | Thickness of projection slices.                        |
| `--num_proj_samples`       | `int`   | `10`     | Number of samples per projection slice. (integer !)    |
| `--flip_proj_direction`    | `bool`  | `True`   | Flip projection direction.                             |
| `--proj_mode`              | `str`   | `"mean"` | Projection mode (`mean` or `max`).                     |
| `--custom_img_treshold`    | `float` | `-1.0`   | Override image auto-thresholding (if ≥ 0).             |
| `--seg_step_size`          | `int`   | `2`      | Step size during segmentation. (integer !)             |
| `--seg_blur`               | `float` | `8.0`    | Gaussian blur sigma for preprocessing.                 |
| `--smooth_factor`          | `float` | `0.001`  | Strength of post-segmentation smoothing. (less = more) |
| `--smooth_iterations`      | `int`   | `200`    | Iterations for surface smoothing. (integer !)          |
| `--seg_fit_sphere_subdiv`  | `int`   | `9`      | Sphere fitting mesh resolution. (integer !)            |
| `--seg_fit_crop_cap_angle` | `float` | `60.0`   | Angle of cropped spherical cap in degrees.             |
